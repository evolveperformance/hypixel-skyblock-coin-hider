# Hypixel Skyblock Cheap Coins Hider

Hides coins on the floor generated by the Coin Talisman in Hypixel Skyblock.

- **Client-side, render-only.** The coins are only not drawn - they still exist and you still pick them up. Nothing is sent to the server.
- **Only active in SkyBlock.** Detected from the sidebar scoreboard title, so it does nothing on other servers or other Hypixel games.
- **Tiny.** One mixin, no config screen, no dependencies besides Fabric API.

## Commands

| Command | What it does |
|---|---|
| `/coinhider` | Toggle on/off (saved to `config/coinhider.txt`) |
| `/coinhider dump` | List nearby dropped items and whether each one is hidden (details in `latest.log`) |

## How coins are detected

Hypixel's coin drops are plain player heads with no custom name and no SkyBlock item ID (`custom_data`). Every real SkyBlock item carries an ID, so real loot is never hidden. Heads named "Coin"/"Coins" are hidden as well.

If something is hidden that shouldn't be (or a coin isn't), run `/coinhider dump` next to it and open an issue with the output.

## Requirements

- Minecraft 26.1.x, Fabric Loader 0.18+, Fabric API, Java 25

## Building

```
./gradlew build
```

The jar ends up in `build/libs/`.
